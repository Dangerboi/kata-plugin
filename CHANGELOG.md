# Changelog

Each plugin keeps its own changelog and releases on its own tag:

- pi, `@dangerboi/kata-pi`: [plugins/pi/CHANGELOG.md](plugins/pi/CHANGELOG.md), tags `pi-v<version>`
- omp, `@dangerboi/kata-omp`: [plugins/oh-my-pi/CHANGELOG.md](plugins/oh-my-pi/CHANGELOG.md), tags `omp-v<version>`
- OpenCode, `@dangerboi/kata-opencode`: [plugins/opencode/CHANGELOG.md](plugins/opencode/CHANGELOG.md), tags `opencode-v<version>`
- Claude Code, `kata-cc`: [plugins/claude-code/CHANGELOG.md](plugins/claude-code/CHANGELOG.md), tags `claude-code-v<version>`

Up to kata-plugin 1.12.0 this file held one changelog for every plugin, and pi and omp released together under `v<version>` tags. Each plugin's changelog now holds its own part of that history.
